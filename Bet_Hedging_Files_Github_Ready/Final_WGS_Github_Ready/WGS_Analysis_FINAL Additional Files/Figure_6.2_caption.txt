Figure 6.2. Relative chromosome III abundance in selected competition populations. For each sample, chromosome III read depth was calculated across 32 consecutive windows, normalised to the length-weighted mean depth of the other nuclear chromosomes excluding chromosome XII, and divided by the corresponding normalised window in the independently sequenced CEN3-WT founder. Chromosome III abundance was therefore first calculated relative to the CEN3-WT founder, which defines the untransformed reference value of 1.000. The resulting values were linearly rescaled for display so that the lowest observed plotted competition value was 1.000. The same transformation was applied to all plotted samples, preserving differences among samples and temporal trajectories. The plotted abundance index is not interpreted as physical chromosome copy number. The dashed trajectory with square markers identifies the successful five-day-cycle lineage. Red and blue line segments indicate the imposed temperature schedule between sampled points.
